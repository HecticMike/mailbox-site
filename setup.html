MailboxOne setup guide

← MailboxOne

1. Install

Run the installer. Windows may say "Windows protected your PC" because the installer is not signed with a paid certificate: choose More info, then Run anyway.

2. Create your Google sign-in key (once, about five minutes)

MailboxOne talks to Gmail and Google Calendar through a small "key" that belongs to you, in your own free Google project. That keeps your mail between you and Google only. MailboxOne walks you through it: on the first screen press Set up Google sign-in. The five steps are:

  1. Create a project named MailboxOne in Google Cloud.
  2. Turn on the Gmail API and the Google Calendar API.
  3. Set up the consent screen (App name MailboxOne, Audience External), add the three permissions the guide lists, and press Publish app. Skipping "Publish app" makes Google sign you out every 7 days.
  4. Create an OAuth client of type Desktop app and download its JSON file.
  5. MailboxOne finds the downloaded file in your Downloads folder (or you can drop it onto the window); press Use this file.

One key serves all the Google accounts you add to MailboxOne.

3. Sign in with Google

Press Sign in with Google. Your browser opens Google's own sign-in page; MailboxOne never sees your password.

"Google hasn't verified this app" is expected: the app is yours and has not been through Google's review. Choose Advanced, then Go to MailboxOne, and leave every box ticked so mail and calendar both work.

Several accounts

Add more accounts from the avatar menu. Switch with Ctrl+1 to Ctrl+9. Give each a name and a colour in Settings → Accounts.

Email links and starting with Windows

Settings → General has Default mail app (email links in web pages open MailboxOne; Windows asks you to confirm) and Start with Windows.

Something not working?

In MailboxOne open Settings → About and support → Copy diagnostics, then paste the result into a message at github.com/HecticMike/mailbox-site/issues. It contains no mail, subjects or addresses.
